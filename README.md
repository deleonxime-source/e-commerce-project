# e-commerce-project

A starter ecommerce application scaffolded with a Node/Express backend and React/Vite frontend.

## Setup

1. Install dependencies
   - `cd backend && npm install`
   - `cd ../frontend && npm install`
2. Create `.env` files from `.env.example`
3. Start the backend and frontend during development
   - `cd backend && npm run dev`
   - `cd ../frontend && npm run dev`

## Structure

- `backend/` — Express API, PostgreSQL access, auth middleware
- `frontend/` — Vite React app with Asgardeo auth integration
